# 末日堡垒 · UI 图标去贴纸化 + 点击交互动效

## 本次改动
- **UI 图标全部重制**：16 张底部菜单图标重新用 AI 生成，并后处理为**圆角透明底**，去掉原来方方正正的“贴纸背景”，统一成带暗色金属圆盘的精致图标。
- **去水印**：生成时右侧/底部留白，再通过 PIL 裁剪右下角「AI生成」水印。
- **菜单点击动效**：`fallout_menu.gd` 重写交互反馈：
  - 悬停：放大 1.10 + 亮度提升
  - 按下：缩放 0.92 + 高亮闪烁
  - 松开：弹性回弹到悬停/常态
  - 选中：持续 1.15 放大 + 1.25 亮度
  - 鼠标指针变为手型
- **缩放中心修正**：设置 `pivot_offset` 为按钮中心，放大/缩小不再偏移。
