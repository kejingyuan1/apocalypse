## 0. 适用范围与一致性声明

- 本文件约束 **全部三端（PC / 移动 / Web）** 与 **全部八系统 GDD** 的视觉可访问层；HUD 三态（运营 / 防御 / 反攻）互斥逻辑以 PVP §4.3、波次 §4.3、能源 §4.4、经济 §4.4、科技 §4.4、社交 §4.4 为权威来源。

## 1. 色彩可访问性（Color Accessibility）

### 1.1 调色板 WCAG 2.1 AA 实测对比度（已核算）

以下为对美术圣经 §2 关键色对在 `UI_BG #1E2230` 上的相对亮度对比度实测（sRGB 线性化 + WCAG 公式）。阈值：正文 ≥ 4.5:1，大文字/UI 图形 ≥ 3:1。

| 前景色（Hex） | 用途 | vs UI_BG `#1E2230` | 结论 |
|---|---|---|---|
| TEXT_PRIMARY `#ECEEF5` | 主文字 | **13.7 : 1** | 超 AAA（≥7） |
| TEXT_SECONDARY `#9AA1B2` | 次文字 | **6.1 : 1** | 达 AA（≥4.5） |
| DANGER_ORANGE `#E8762E` | 威胁/危险文字 | **5.3 : 1** | 达 AA |
| AMBER_WARM `#E8923D` | 营火/人口暖橙文字 | **6.5 : 1** | 达 AA |
| ENERGY_CYAN `#48B6E8` | 能源/信息文字 | **6.9 : 1** | 达 AA |
| WARN_YELLOW `#EAC23A` | 警告文字 | **9.3 : 1** | 达 AA |
| UI_SUCCESS `#6CC04A` | 成功文字（配 ✓） | **7.0 : 1** | 达 AA |
| 废料 `#8A8F9C` | 资源图标（灰） | **4.9 : 1** | 达 AA（图标图形 ≥3 更稳） |
| 晶体 `#48B6E8` | 资源图标（冷蓝） | **6.9 : 1** | 达 AA |
| **生物质 `#7E8856`** | 资源图标（橄榄绿） | **4.2 : 1** | ⚠ **文字不达标**（<4.5），仅作图形（≥3 通过） |
| 人口 `#E8923D` | 资源图标（暖橙人形） | **6.5 : 1** | 达 AA |
| WARN_YELLOW on UI_BORDER `#0E1118` | 黄黑警示斜纹 | **11.0 : 1** | 达 AAA |

> **核算结论**：主/次文字、威胁/能源/警告/成功文字均达 AA（多数达 AAA）。唯一风险是 **生物质橄榄 `#7E8856` 作小字号文字仅 4.2:1**——见 §1.4 风险与修正。

### 1.2 暖橙威胁色在三类色盲下的可读性

采用 CVD 模拟（protan/deutan/tritan，建议 Brettel 或 Machado 矩阵，Phase 3 色盲模拟开关实现，见 §1.5）。单层暖橙 `DANGER_ORANGE` 在三类色盲下的表现：

| 色盲类型 | 暖橙 `#E8762E` 的观感变化 | 是否仍可辨 | 依赖的非色彩通道 |
|---|---|---|---|
| **Protanopia（红色盲）** | 暖橙变暗、向棕褐偏移，明度保留 | ✅ 可辨（明度差 vs 暗底仍 ~5:1） | 图标（skull/⚠）+ 文字 + 脉冲 |
| **Deutanopia（绿色盲，最常见）** | 暖橙向黄绿轻微偏移，明度保留；**与绿（UI_SUCCESS/橄榄）色相趋同** | ✅ 可辨，但须防与"成功绿"混淆 | **✓（成功）vs ⚠/skull（危险）图标强制区分** |
| **Tritanopia（蓝色盲，罕见）** | 暖橙几乎不受影响；受影响的是 `ENERGY_CYAN` 与 `WARN_YELLOW` | ✅ 可辨 | 能源 `⚡` / 警告斜纹等图标 |

> **核心结论**：暖橙威胁色靠**高明度 + 图标/形状/文字**三重通道，在三类色盲下均可读；色盲模拟开关用于开发期验证，不要求玩家默认开启。

### 1.3 红绿非唯一区分 · 落地检查清单

所有语义信号须满足「≥2 通道」。逐项落地清单（对齐美术 §9.1 / 各 GDD）：

| 语义 | 颜色通道 | 必配非色彩通道（图标/形状/位置/文字） | 来源 |
|---|---|---|---|
| 低血量危急 | `DANGER_ORANGE` 条 | ❤ 图标 + 脉冲 + 音效 | 美术 §9.1 |
| 安全/成功 | `UI_SUCCESS` 绿 | ✓ 图标（**非纯绿**） | 美术 §2.6 / §9.1 |
| 警告 | `WARN_YELLOW` 黄 | 黄黑斜纹 `WARN_YELLOW` + ⚠ | 美术 §9.3 / §2.3 |
| 断电 | `DANGER_ORANGE` 描边 | ⚠ 图标 + 文字"断电房 N" + 辉光熄灭 | 能源 §4.4 / 科技 §4.4 |
| 能源供需 | 充足=蓝 `ENERGY_CYAN` / 赤字=`DANGER_ORANGE` | ⚡（供）/ ⚠（断）+ 数字 `Supply/Demand` | 能源 §4.4（R13 精简单条） |
| 尸潮来袭 | `DANGER_ORANGE` vignette | skull 图标 + 来袭方向箭头 + 音效 | 波次 §4.3 |
| 敌人/友方 | 敌=橙 `DANGER_ORANGE` / 友=蓝 `ENERGY_CYAN` 边框 | 旗帜/准星图标 + 文字 | 波次 §7.3 / 离线 §3.4 / 社交 §4.4 |
| 资源 4 类 | 废料灰/晶体蓝/生物质橄榄/人口橙 | 各配 §2.7 专属图标 + 数字 + 涨跌箭头 | 美术 §2.7 / §7.2 |
| 小地图丧尸分型 | （不靠颜色） | ●Walker / △Runner / ■Brute / ◆Spitter / ○Bloater | 美术 §5.2 / §9.1 |
| HUD 三态互斥 | 防御/反攻**均用暖橙**（单体系） | 运营=⌂/齿轮静态；防御=skull+盾+vignette（受）；反攻=旗帜+准星+外向箭头（攻）+ 文字标签 | PVP §4.3 / 波次 §4.3 |

> **关键约束**：因单体系「防御态」与「反攻态」同为暖橙，二者**绝不可靠颜色区分**——必须用「图标形态（盾/受 vs 旗/攻）+ 方向（内向/外向箭头）+ 文字标签（运营/防御/反攻）」三重组区分（详见 §2.2）。

### 1.4 风险与修正（与美术圣经一致性要点）

- **R-A11Y-1（生物质橄榄文字对比度不达标）**：`#7E8856` 在 `UI_BG` 上仅 4.2:1，低于正文 4.5:1。修正：资源数字**一律用 `TEXT_PRIMARY` 白字**，生物质仅作**图标填色（图形 ≥3:1 通过）**，不用于小字号文字。
- **R-A11Y-2（丧尸 vs 地面明度偏低）**：`ZOMBIE_SKIN #6E7A55` 在废土地面 `GROUND_WASTE #4A4636` 上仅约 **2.1:1**（远低于 AA）。修正：丧尸识别**不得依赖肤色**，必须靠 ① 剪影（§5.1 一级辨识）+ ② `INFECT_GLOW` 感染辉光（眼/血管）+ ③ **暗色描边/厚涂硬阴影轮廓**（§4 厚涂硬阴影）把明度边界拉高；外围战场建议加一层低 alpha 暗角降低地面噪声。
- **R-A11Y-3（GDD 与美术圣经「红色」不一致 — 必须纠正）**：PVP §4.3、经济 §4.4、建造 §3.4/§6 多处出现「红色警报框 / HUD 红框 / 红色」。这与美术 §2.3「不引入第二层红、单层暖橙」铁律冲突。**统一改为 `DANGER_ORANGE #E8762E` + 图标/脉冲**，删除一切"第二层红"表述。本文档据此裁定，请对应 GDD 在评审时同步修订（属一致性回填，不推翻已裁定项）。
- **R-A11Y-4（WEAPON_RED 材质色非信号）**：`WEAPON_RED #C0392B` 仅作武器主体材质（§2.2），**不得**用于任何状态/警示信号，避免与暖橙威胁色混淆。

### 1.5 色盲模拟开关（Phase 3 实现口径）

- 提供 **deuteranopia / protanopia / tritanopia** 三档预览开关 + 「正常」共四态，开发期与可选玩家模式可用。
- 实现：在渲染末端（WorldEnvironment 后处理或视口 shader）对已渲染帧做 CVD 矩阵变换；**不改动资产本身**，仅视觉模拟。
- 用途：① Phase 5/6 自测（开模拟逐屏核查无"纯色唯一区分"）；② 玩家「强制色盲模式」可选（极致档默认开，见 §5）。

## 2. 视觉可读性（Visual Readability）

### 2.1 32×32 tile 在 640×360 下的信息密度上限

设计分辨率 640×360（16:9），tile 32×32（美术 §3）：

| 相机层级（美术 §3.3） | 可见格数（640×360 / 32px） | 单 tile 信息密度上限 |
|---|---|---|
| OVERVIEW 0.6× | ≈ 33×18 | 仅"占位类型"剪影，无细信息 |
| NORMAL 1.0× | ≈ 20×11（≈220 格） | 1 个主体 + 1 个状态图标（≤2 信号） |
| DETAIL 1.5× | ≈ 13×7 | 可显居民/资源细节（居民 24×32） |

- **上限规则**：每个 32×32 tile 在世界空间**仅承载 ≤2 个语义信号**（「占格类型」+「状态」），且状态用图标而非文字（文字在缩放后破碎）。文字/数字/条形一律在**屏幕空间 HUD** 以更高分辨率绘制（美术 §3.2 可读性保障 ③）。
- 桌面/移动同屏信息密度一致（三端统一抽象，GDD 共性原则 P5）；避免 NORMAL 态单屏压入 >220 格的细信息。

### 2.2 HUD 三态在色盲下的非色彩区分（核心）

单暖橙体系下，"防御态"与"反攻态"共用 `DANGER_ORANGE`，**必须**用下表非色彩通道互斥（对齐 R13 认知过载兜底）：

| 状态 | 触发 | 暖橙用法 | 非色彩区分（必备） | 动效 |
|---|---|---|---|---|
| **运营态** | 和平窗口 | 静态（无脉冲） | ⌂/齿轮图标 + 文字「运营」；资源/电力条常驻 | 能源 2s 呼吸（可关） |
| **防御态** | 被 PVE/PVP 进攻 | 全屏边缘脉冲 vignette（≤2–3Hz） | **skull 💀 + 盾牌图标** + 内向来袭箭头 + 文字「防御」 | 轻抖（仅波次/PVP，日常禁） |
| **反攻态** | 本方发起 PVP | 顶部进攻条（同橙） | **旗帜 + 准星图标** + 外向攻击箭头 + 文字「反攻」 | 掠夺进度条 |

> 三态**互斥切换**（PVP §4.3）：同一时刻仅一态主显，避免决策轰炸（R3/R13）。色盲下三态靠「图标形态 + 箭头方向 + 文字标签」一眼区分，颜色仅作氛围强化。

### 2.3 像素字体最小可读字号

对齐美术 §2.8 / §7.1，并给出 640×360 缩放后结论：

| 场景 | 设计分辨率字号（@1×） | 整数缩放后（2×/3×） | 达标性 |
|---|---|---|---|
| 正文（HUD/战报） | ≥ 10px，加粗像素字重 | 20 / 30 设备 px | 对比度 13.7:1（AA+AAA），**达标** |
| 标题 | ≥ 14px | 28 / 42 设备 px | 达标 |
| 移动端正文 | ≥ 12px（设计 +2px） | 24 / 36 设备 px | 达标 |
| 禁用态 `TEXT_DISABLED` | ≥ 10px | — | 对比度 ≥2:1（仍须可辨，§9.2） |

> **WCAG AA 小字号结论**：对比度比值与缩放无关（同色），10px 正文在 `TEXT_PRIMARY` 即 13.7:1，远超 AA（4.5）。唯一风险是 **1× 直显（640×360 不放大）在低 DPI 屏上物理过小**——强制 PC 端有效显示缩放 ≥2×（2×→1280×720 / 3×→1920×1080），移动端按 dp 映射；1× 仅作调试态。增强/极致档进一步放大字号（§5）。

## 3. 操控可访问性（Input Accessibility）

### 3.1 移动端触屏目标最小尺寸与误触防护

- **最小触摸目标**：Android **≥ 48dp**、iOS **≥ 44pt**（等效）。映射到设计分辨率：底部操作栏按钮绘制 ≥ 48×48 设备无关像素（GDD 各端适配均载「触摸目标 ≥48dp」）。
- **误触防护**（对齐建造 §4.2 / 各 GDD）：
  - 破坏性操作（拆除/升级/发起 PVP/踢人）**二次确认弹窗**（社交 §4.2 集结确认）；
  - 网格吸附（建造 §4.2）+ 拖拽预览，防误放；
  - 长按弹参数（移动端），避免单点误触发；
  - 冷却防滥用（踢人 30s，社交 §5.1；拆除 Cd 30s，建造 §3.3）；
  - 战斗锁定态建造坞/实验切换置灰（建造 §6），防误触无效指令。

### 3.2 PC 键位可重映射

- 所有系统默认快捷键（R 加固/F 集火/C 反击、E 切换/P 降载、M 切换/C 转化、B 建造坞/R 旋转、X 实验、T 陷阱、S 护盾…）**必须可重映射**，且存储于用户配置（不写死）。
- **R-A11Y-5（默认键位冲突 — 须解决）**：跨系统出现同键复用——`C` 同时用于「反击(wave) / 转化(economy) / 取消(tech)」，`R` 同时用于「加固·集火(wave) / 启动研究(tech) / 旋转(build) / 设自动优先级」。修正：① 重映射为强制项，② 在默认方案里按上下文（当前激活面板）消歧或改用无冲突键，③ 主理人/engineering-lead 评审时锁定无冲突默认表。
- 提供「按键冲突检测」：保存时若两激活态同键则提示。

### 3.3 Web 端无鼠标场景降级

- **键盘全可操作**：所有核心循环（放置/守/扩张/出征/社交）可由键盘 + 快捷键完成（Web 端键位与 PC 一致）。
- **焦点可见**：UI 元素具明确焦点框（`UI_BORDER_LT` 高亮，≥3:1 边界），Tab 顺序符合视觉阅读顺序。
- **禁用右键冲突**：Web 禁用浏览器右键菜单（GDD 各端适配），避免与游戏指令冲突；提供 Esc/关闭键统一退出浮层。
- **无鼠标也能读 HUD**：三态/资源/电力条均有键盘可达的 tooltip 与屏幕阅读器文本标签（极致档，见 §5）。

## 4. 认知负荷与光敏安全（Cognitive Load & Photosensitivity）

### 4.1 对齐 R13（波次/能源）认知过载兜底

- **HUD 三态互斥**：运营态电力条常驻、防御/反攻态弱化（能源 §4.4 R13 ①）；不三态同屏暴露。
- **供需条精简**：电力条为**单条 + 数字**（`Supply/Demand`），不堆多通道（能源 §4.4 R13 ②）；赤字段整条转暖橙 + 脉冲。
- **断电用 ⚠ 图标非纯色**：断电房 `DANGER_ORANGE` 描边 + ⚠ + 文字"断电房 N"，不以颜色 alone 表达（能源 §4.4 / 科技 §4.4 R13 ②）。
- **降载默认 AutoPriority**：免去手动决策（能源 R13 ③）；冗余用「满蓝=安全」直觉表达。
- 资源条在防御/反攻态保留但弱化，消耗实时数字飘（不堆红框，R-A11Y-3 已统一为暖橙）。

### 4.2 闪烁 / 光敏安全（Epilepsy-Safe）

对齐 WCAG 2.3「一般闪动 ≤3 次/秒（含红闪 ≤1 次/秒）」，并落实美术 §8 动效禁忌：

- 全屏脉冲（尸潮 vignette、断电告警）频率 **≤ 2–3 Hz**，且**禁用红色**（用暖橙），降低光敏触发风险。
- **减动效（关抖屏）开关**（美术 §9.3 可配置）：开启后
  - 关闭全屏抖屏/受击震屏（美术 §8.3 日常经营本就禁抖屏，仅波次/PVP 用，减动效档全关）；
  - 脉冲/呼吸降速或停（能源 2s 呼吸、营火噪声闪烁改为静态或低频）；
  - Bloom 强度下调或关（移动端本就可关，§4.3）；
  - 开火闪光 `WEAPON_MUZZLE` 3 帧瞬态保留但去全屏叠加。
- 强制：任何 ≥25% 屏幕面积的亮闪持续 < 0.5s 且频率 < 3Hz；红闪（本项目本就无红）绝对禁止。
- 「减动效」开关在 **增强/极致档默认开启**（§5）。

## 5. 分级档位（Accessibility Tiers — 3 档预设）

> 注：美术圣经 §9 原拟 Basic/Standard/Comprehensive/Exemplary 四档命名；本任务按主理人要求交付 **标准/增强/极致 3 档**，其中「极致」≈ Exemplary。三档**递进叠加**（增强包含标准，极致包含增强）。

### 5.1 标准档（Standard · 默认出厂）

= 美术圣经 §9 全线基线，所有玩家默认获得：

- [x] 色盲友好设计：所有语义 ≥2 通道（图标+形状+文字，§1.3）
- [x] WCAG AA 文本对比度（正文 4.5 / 图形 3，实测见 §1.1）
- [x] HUD 三态互斥 + 图标/方向/文字区分（§2.2）
- [x] 移动端触摸目标 ≥48dp；PC 键位可重映射；Web 键盘可达
- [x] 色盲模拟开关（开发/可选）
- [x] 减动效开关（默认关，玩家可选）
- [x] 数据双通道（条形 + 数字）、图标必配文字/tooltip

### 5.2 增强档（Enhanced）

在标准档之上追加：

- [x] **高对比模式**：僵尸/敌人加粗描边（解决 R-A11Y-2）；面板双描边加厚（`UI_BORDER` + `UI_BORDER_LT`）；达标项向 AAA 收拢
- [x] **字体放大 +2px**：移动端正文 12px、标题 16px；PC 正文 12px
- [x] **减动效默认开启**：关全屏抖屏、降频脉冲/Bloom
- [x] **色盲模拟默认开启**（deuteranopia 最常见，可切三型）
- [x] **图标下常显文字标签**（不依赖 hover/长按）
- [x] 键位提供「无冲突预设方案」+ 冲突检测

### 5.3 极致档（Exemplary）

在增强档之上追加（≈ WCAG Exemplary）：

- [x] **强制高对比主题**：全界面 AAA 对比度优先；暗角/噪点降噪；可选单色描边叠层
- [x] **大字模式**：正文 14px / 标题 18px（设计 @1×），物理尺寸最大化
- [x] **完整键盘导航（Web 无鼠标）**：核心循环 0 鼠标完成；焦点环显著；屏幕阅读器标签全覆盖
- [x] **全威胁音频化**：尸潮（方向音 + 警报）、断电（⚠ 提示音）、三态切换（各异 SFX）独立音效，视觉+听觉双通道
- [x] **字幕/字幕条**：所有重要 AI 语音/系统播报配文字（PVP/离线战报/社交战报）
- [x] **HUD 可定制**：可隐藏/重排非必要模块，降低认知负荷（R3/R13）
- [x] **文本缩放独立于分辨率**：字号滑块不影响世界缩放（640×360 整数缩放不变）

## 6. 验收清单（Phase 5/6 自测 Checklist）

以下条目供开发 Phase 5（构建）/ Phase 6（验收）逐条勾选；每条须有「开色盲模拟」与「各端」复测。

### 6.1 色彩与对比度
- [ ] 所有语义信号在「正常」与「三档色盲模拟」下均**不依赖单一颜色**即可辨识（逐屏核查 §1.3 清单）
- [ ] 生物质 `#7E8856` 仅作图标填色，资源数字用 `TEXT_PRIMARY`（修正 R-A11Y-1）
- [ ] 丧尸在世界空间具暗色轮廓 + `INFECT_GLOW` 辉光，肤色非唯一 ID（修正 R-A11Y-2）
- [ ] 八份 GDD 中「红色警报框/红框」表述已全部替换为 `DANGER_ORANGE` + 图标（修正 R-A11Y-3）
- [ ] 设备实机上抽样测量正文 ≥4.5:1、UI 图形/图标 ≥3:1（用 §1.1 基线）
- [ ] HUD 三态在色盲模拟下靠图标/箭头/文字区分，无「同橙难辨防御/反攻」

### 6.2 视觉可读性
- [ ] 单 tile 世界空间 ≤2 信号；文字/数字仅在屏幕空间 HUD 绘制
- [ ] 像素字体：PC 有效显示缩放 ≥2×；正文 ≥10px@1× 且加粗
- [ ] 小地图丧尸分型用形状（●/△/■/◆/○）非颜色

### 6.3 操控
- [ ] 移动端触摸目标实测 ≥48dp（iOS ≥44pt 等效）
- [ ] 破坏性操作均有二次确认；网格吸附 + 长按弹参防误触
- [ ] 所有快捷键可重映射且持久化；默认方案无激活态键冲突（修正 R-A11Y-5）
- [ ] Web 端键盘完成核心循环；焦点框可见（≥3:1 边界）；右键冲突禁用

### 6.4 认知与光敏
- [ ] 全屏脉冲 ≤3Hz 且非红；减动效开启后无抖屏/无高频闪
- [ ] HUD 三态同屏仅一态主显（互斥）
- [ ] 电力条单条 + 数字；断电用 ⚠ + 文字（非纯色）
- [ ] 光敏测试：无 ≥25% 亮闪 >3Hz / 无红闪

### 6.5 分级档位
- [ ] 标准/增强/极致三档预设可在设置内一键切换并即时生效
- [ ] 增强档：高对比 + 字号 +2px + 减动效默认开 + 色盲模拟默认开
- [ ] 极致档：大字 14/18px + 完整键盘导航 + 威胁音频化 + 字幕 + HUD 可定制
