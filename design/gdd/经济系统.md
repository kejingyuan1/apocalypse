# 经济系统 GDD（Game Design Document）

> 阶段：Phase 2 系统设计（第三个系统 · 建造系统的直接下游依赖）
> 服务支柱：P3 看得见的成长（Visible Progression）
> 对应核心动词：Harvest（生产）
> 依赖系统：建造系统（房间占位决定产出容量）/ 波次系统（消耗存量）/ 实时 PVP 对战系统（掠夺结算）
> 文档负责人：design-strategist（文策渊）
> 备注：本系统为 MVP 核心层必需；概念阶段四大红线中，本系统为 **R6 经济失衡** 的主要承载与对冲系统，其余红线由关联系统兜底。承接《游戏概念文档》§2.2 / §6 / §7 / §9 / §12 与《建造系统 GDD》《实时 PVP 对战系统 GDD》结构。

---

## 1. 系统概述

经济系统管理 **废料(Scrap) / 晶体(Crystal) / 生物质(Biomass)** 三种资源的产出、存储、转化、消耗与掠夺流转，是「看得见的成长」（P3）支柱的承载核心——它把"建造→扩张→升级"的进度转化为可量化、可稀缺、可博弈的资源流，让每一次成长都有清晰的资源成本与回报正反馈。

一句话定义：**经济系统 = 把三类资源流（生产 / 存储 / 消耗）编织成一条"产得出、存得满、花得掉、抢得走"的闭环，用软上限+离线衰减+进攻消耗+波次消耗四重闸门对冲通胀。**

> 与建造系统的依赖关系：建造系统的放置/升级/拆除全部以本系统资源为货币（见建造系统 §7）；本系统的产出容量由建造系统的房间占位决定（见 §3.1 / §7）。两者逻辑紧耦合，本 GDD 紧随建造系统之后拆解。

## 2. 设计目标与验收标准

### 2.1 设计目标
- G1 三类资源各有稀缺角色：废料=通用基石、晶体=高技术、生物质=人口维持，制造明确取舍（P3 成长可见）
- G2 软上限封顶：任何资源存量不超过软上限，溢出弃置，杜绝无限囤积（R6 防通胀）
- G3 离线衰减：离线产出大幅下降且久离线再降，杜绝挂机刷资源
- G4 产出依赖布局：生产/居住房间的占位、等级、能源邻接决定产出容量（呼应 P1 空间即策略）
- G5 双威胁消耗：PVE 波次与 PVP 掠夺持续消耗存量，使产出≫消耗不可持续（R6 核心对冲）
- G6 三端统一：PC / 移动 / Web 共用同一套 HarvestCommand 抽象，跨端体验一致（P5 低门槛高深度）

### 2.2 验收标准（MVP 门控）
| 编号 | 验收项 | 通过条件 |
|---|---|---|
| AC1 | 三类资源流转 | 废料/晶体/生物质均可被生产、消耗、显示，且单位一致 |
| AC2 | 软上限生效 | 任一资源达到软上限后，后续产出被弃置（不入库），HUD 显示"已满" |
| AC3 | 离线衰减实测 | 离线（>5min 无输入）产出 ≤ 在线 30%；离线 >8h 再降至 10% 实测达标 |
| AC4 | 波次消耗 | 每波结算扣除弹药(废料)/应急(生物质)，存量可被正确扣减且不为负 |
| AC5 | 掠夺对齐 | 掠夺结算数值与 PVP GDD §5.5 公式一致；进攻方软上限溢出弃置 |
| AC6 | 生产力随布局 | 同等级下，落于能源半径内的生产房产出 +10%；断能降级至 30% 生效 |
| AC7 | 三端一致 | PC / 移动 / Web 同一 HarvestCommand 在服务端结算结果完全一致 |

## 3. 核心机制

### 3.1 三类资源与生产房间（引用概念 §2.2 / §7）
资源由**生产型房间**在计时 tick 内持续产出；产出容量由建造系统的房间占位、等级、能源邻接决定。

| 资源 | 角色定位 | 主产房间 | 房间尺寸 | 次产/转化来源 |
|---|---|---|---|---|
| 废料 Scrap | 通用基石：建造、升级、弹药主耗 | 生产 Production | 3×2（6 格） | 拆解返还、掠夺获得 |
| 晶体 Crystal | 高技术：武器/科技/能源核心升级耗 | 生产 Production（萃取模式）/ 实验 Lab（转化） | 3×2 / 3×3 | 废料转化（§5.4） |
| 生物质 Biomass | 人口维持：居住升级、医疗、应急修复 | 居住 Housing | 2×2（4 格） | 掠夺获得 |

**产出触发与归属**：每个生产型房间按固定 tick（建议 1 tick = 1s）累加产出；库存实时写入服务端，客户端仅接收快照（引用概念 R2 防作弊）。房间被拆/断电即停止或降级产出（见 §6）。

### 3.2 软上限（引用概念 R6 · 防通胀）
每个资源设有**软上限 SoftCap_r**，达到后新增产出被弃置（不直接入库），仅保留 HUD 提示，不进入经济循环。
- **基础软上限**来自堡垒等级基线；**仓储 Storage 房间（3×2，延伸层 Lv5 解锁）逐间提升上限**（引用概念 §7 面积矩阵）。
- 公式：`SoftCap_r = Base_r + BonusPerStorage_r × N_storage`
  - `Base_r`：基础软上限（随堡垒等级微调，见 §5.2）
  - `BonusPerStorage_r`：每座仓储房加成
  - `N_storage`：当前已建成的仓储房数量（受建造系统房间数上限约束，见建造系统 §5.2）
- **软上限与掠夺对齐**：PVP 进攻方掠夺所得同样受自身软上限约束，超出部分弃置（与 PVP GDD §5.5 上限约束一致，R6）。

### 3.3 离线产出衰减（防挂机刷资源 · 引用概念 R6）
玩家离线（连续 >5min 无有效输入）时，堡垒由服务端按"离线产出系数 K_offline"节流生产，杜绝挂机累积：
- **离线 ≤ 8h**：`K_offline = 0.30`（仅在线产能的 30%）
- **离线 > 8h**：`K_offline = 0.10`（长期挂机再降，逼近停滞）
- 离线产出仍受软上限约束；离线期间不触发任何主动消耗（波次由托管 AI 消耗，见 §3.5 备注）。
- 设计意图：在线才有满产，把"守在线上"变成正向激励（呼应概念 §2.3 断线脆弱动态），切断"挂机即富"的通胀路径。

### 3.4 PVP 掠夺消耗（与 PVP GDD §5.5 严格对齐）
掠夺从防守方存量中按既定公式抽取，是本系统"消耗闸门"之一：
`Loot_r = StoredDef_r × R_loot × K_ratio × K_online`
| 变量 | 含义 | 单位 | 取值 |
|---|---|---|---|
| `Loot_r` | 进攻方掠夺到的资源 r 总量 | 资源单位 | 输出 |
| `StoredDef_r` | 防守方资源 r 存量 | 资源单位 | 实时读取 |
| `R_loot` | 基础掠夺比例 | 比例 | 在线实战 = 0.50；护盾生效 = 0（引用 PVP §5.3） |
| `K_ratio` | 收益衰减系数 | 比例 | ∈[0.25,1]，查 PVP §5.2 |
| `K_online` | 防守方在线系数 | 比例 | 在线 = 1.0；离线护盾外 = 0.10（查 PVP §5.5） |

- **上限约束**：`Loot_r ≤ StoredDef_r`（存量保护，见 §6）；进攻方所得计入自身库存但**不超自身软上限**，溢出弃置。
- **进攻方自身消耗**：发起一次 PVP 需预缴"出击成本"（弹药(废料)/应急(生物质)），从进攻方存量扣减（见 §5.3），构成"进攻也花钱"的双边消耗。

### 3.5 波次消耗（弹药/能源消耗 · 引用概念 R6）
每个 PVE 波次结算时从玩家存量扣减"防御成本"，是本系统另一条持续消耗闸门：
- **弹药消耗**：每波扣除 废料（制造塔弹），公式 `AmmoCost(w) = A_base × (1 + 0.08×(w−1))`，`A_base = 20`。
- **应急消耗**：每波扣除 生物质（战后修复/医疗），`BioCost(w) = B_base × (1 + 0.05×(w−1))`，`B_base = 10`。
- **能源关联**：波次期间武器塔需处于供电半径内才全额开火；断能塔不耗弹药但 DPS 降级（与能源网络系统协同，消耗侧仅在有效开火时计弹药）。
- **离线托管**：玩家离线时自动防御 AI 托管战斗，仍按上述公式消耗存量（引用概念 §10.2），保证离线也持续泄库、不产生"离线屯资源"漏洞。
- 设计意图：波次每 90s 一次（引用概念 §9.1），形成周期性稳定泄流，使"纯囤积不防守"不可持续（R6 核心对冲）。

## 4. 玩家接口（三端统一抽象层）

### 4.1 抽象动词（P5 低门槛高深度）
统一为 3 类 Harvest 指令，各端仅做输入翻译，服务端为唯一真相源：
- **切换模式（SetMode）**：把生产房在"废料 / 晶体萃取"间切换（决定产什么）。
- **转化（Convert）**：实验房将废料批量转晶体（一次性/持续模式）。
- **领取/归集（Claim）**：手动归集散落产出（离线回归或活动奖励入账，可选；默认自动入账）。

### 4.2 各端适配
| 端 | 输入方式 | 关键适配 |
|---|---|---|
| PC | 点击生产房弹"产物选择"浮层 + 快捷键（M 切换模式 / C 转化） | 悬停显示该房实时产出率与软上限进度 |
| 移动 | 点选房间 → 底部产物切换条 + 长按弹参数 | 触摸目标 ≥48dp；切换条大按钮防误触 |
| Web | 同 PC，限最大画布 | 禁用右键菜单冲突；键位与 PC 一致 |

### 4.3 统一指令结构（设计抽象，非实现代码）
所有端输入归一为：
```
HarvestCommand {
  type: SetMode | Convert | Claim
  roomId: id                 // 目标房间（SetMode/Convert 用）
  targetResource: Scrap|Crystal|Biomass   // SetMode 的目标产物 / Convert 的目标产出
}
```
> 客户端**仅发送上述动词指令**；产出累加、软上限判定、转化扣减、掠夺结算全部以服务端为准（引用概念 R2）。

### 4.4 HUD 呈现（引用 PVP GDD §4.3 三态）
- **运营态**：顶部资源条显示 废料/晶体/生物质 当前值 / 软上限进度条 + 各资源每分钟净变化率。
- **防御态 / 反攻态**：资源条保留但弱化，波次/掠夺消耗实时扣减动效（暖橙 −N 飘字 + ⚠ 图标），避免认知过载（R3 兜底）。
> **视觉一致性声明**：资源扣减飘字统一用暖橙（DANGER_ORANGE #E8762E）+ ⚠ 图标，不引入第二层红色，遵循《美术圣经》§2.3 单层暖橙铁律。

## 5. 关键数值

### 5.1 各生产房间产出率（Lv1 基准 · 每分钟 / 每间）
| 房间 | 尺寸 | 模式 | 废料/min | 晶体/min | 生物质/min | 等级缩放 |
|---|---|---|---|---|---|---|
| 生产 Production | 3×2 | 废料（默认） | 12 | 0 | 0 | ×(1+0.25×(lv−1))，lv≤5 |
| 生产 Production | 3×2 | 晶体萃取 | 0 | 1.5 | 0 | 同上 |
| 居住 Housing | 2×2 | 生物质 | 0 | 0 | 5 | ×(1+0.2×(lv−1))，lv≤5 |
| 实验 Lab | 3×3 | 转化（耗废料产晶体） | −20 | +2.5 | 0 | 见 §5.4 |

- **能源邻接加成**：生产房落入能源半径内，产出 ×1.10（引用建造系统 §3.5 能源⊕生产 +10%）。
- **示例**：Lv3 生产房（废料模式）+ 能源邻接 = `12 × (1+0.25×2) × 1.10 = 12 × 1.5 × 1.10 = 19.8/min`。

### 5.2 软上限值表
| 资源 | 基础软上限 Base_r（Lv1） | 每仓储房加成 BonusPerStorage_r | Lv6 满配估算（4 仓储） |
|---|---|---|---|
| 废料 Scrap | 500 | +300 | 500 + 1200 = 1700 |
| 晶体 Crystal | 200 | +150 | 200 + 600 = 800 |
| 生物质 Biomass | 150 | +100 | 150 + 400 = 550 |

> 基础软上限随堡垒等级线性抬升（+50/级，满级 Lv6 废料基线约 750），使成长可见且上限随布局扩张（P3）。仓储房为延伸层 Lv5 解锁（引用概念 §8）。

### 5.3 离线衰减系数与 PVP 出击成本
| 参数 | 值 | 说明 |
|---|---|---|
| 离线产出系数 K_offline（≤8h） | 0.30 | 离线产能仅为在线 30% |
| 离线产出系数 K_offline（>8h） | 0.10 | 长期挂机再降 |
| PVP 出击成本（每次发起） | 废料 50 + 生物质 20 | 进攻方预缴弹药(废料)/应急(生物质)，从存量扣 |
| 软上限溢出弃置 | 是 | 产出/掠夺超自身软上限部分不入库存 |

### 5.4 资源间转化率（废料 → 晶体）
| 转化路径 | 输入 | 输出 | 转化比 | 承载房间 |
|---|---|---|---|---|
| 萃取模式 | 废料 0（直接产晶体，不耗废料） | 晶体 1.5/min | — | 生产 Production（晶体萃取） |
| 实验转化 | 废料 20/min | 晶体 2.5/min | **8 废料 → 1 晶体（0.125）** | 实验 Lab（转化模式） |

> 转化机制让"富废料、缺晶体"的玩家有确定性出路，避免单一资源卡死进度（P3 成长连续），同时转化本身消耗废料，进一步泄库（R6）。

### 5.5 波次消耗公式与示例
| 波次 | 弹药消耗（废料） | 应急消耗（生物质） | 公式 |
|---|---|---|---|
| W1 | 20 | 10 | `Ammo=20×(1+0.08×0)=20`；`Bio=10×(1+0.05×0)=10` |
| W5 | 26 | 12 | `20×1.32=26`；`10×1.20=12` |
| W10 | 38 | 14 | `20×1.72=38`；`10×1.45=14` |

> 90s 周期下约 40 波/小时 → 每小时稳定泄流 废料 ≈ 800–1500、生物质 ≈ 400–600，构成持续消耗闸门（R6）。

## 6. 边界与异常

| 场景 | 处理 |
|---|---|
| 软上限溢出 | 达到 SoftCap_r 后新增产出直接弃置，不入库；HUD 资源条变满并显示"已达上限"；掠夺所得超进攻方软上限同样弃置（R6） |
| 能源断供（断供降级） | 生产房脱离能源半径 → 产出降级至在线基准的 30%（brownout）；恢复供电即时回到 100%（含邻接 +10%） |
| 房间被拆/移动 | 该房产出立即停止；移动为事务操作（引用建造系统 §3.3），中途失败不丢产出 |
| 掠夺后负值保护 | 防守方存量扣减后 `floor(StoredDef_r) = max(0, StoredDef_r − Loot_r)`，永不为负；`Loot_r ≤ StoredDef_r`（与 PVP GDD §5.5 一致） |
| 离线回归 | 离线期间按 K_offline 累加，回归时一次性入账但受软上限封顶；超 8h 段按 0.10 计 |
| 断线重连 | 资源以服务端快照为准；客户端仅渲染，不重算（R2） |
| 转化房资源不足 | 实验房转化模式当废料不足时暂停产出晶体，不借贷、不扣负 |
| 双倍消耗冲突 | 同一 tick 内波次与 PVP 同时扣减，按服务端顺序串行结算，单次结算后均做负值保护 |
| 软上限突变（拆仓储房） | 拆仓储导致 SoftCap 下降时，超出部分存量**保留不删**，仅停止后续入库直至回落至新上限内 |

## 7. 依赖系统

| 依赖系统 | 对本系统的影响 |
|---|---|
| 建造系统 | 房间占位决定产出容量：生产/居住房数量与尺寸决定基础产能；仓储房数量决定软上限；升级提升产出率；拆除返还资源（引用建造系统 §3.3 / §7） |
| 波次系统 | 每波结算从存量扣弹药(废料)/应急(生物质)，是持续消耗闸门（§3.5）；断能塔影响有效开火与弹药消耗（§3.5） |
| 实时 PVP 对战系统 | 掠夺结算按 §5.5 公式抽取防守方存量；进攻方出击成本与软上限溢出弃置由本系统提供（§3.4）；护盾/离线系数来自 PVP GDD（§5.3） |
| 能源网络系统 | 生产房需落能源半径才满产；断能降级至 30%（§6）；邻接 +10% 加成来源（§5.1） |
| 科技/实验系统 | 实验房转化模式与科技对产出/软上限的潜在增益来源（§5.4；延伸层） |

## 8. 设计风险与缓解

### 8.1 核心风险 R6：经济失衡（生产≫消耗 → 资源通胀）
**风险机理**：若三类资源净产出长期高于消耗，存量会无限堆积，使建造/升级失去稀缺感，进度正反馈（P3）崩塌，并让"囤积流"成为主导策略（违反四大红线之经济失衡）。

**四重对冲闸门（均已用具体数值落地）：**

| 闸门 | 机制 | 具体数值 | 对冲效果 |
|---|---|---|---|
| ① 软上限 | 存量封顶，溢出弃置（§3.2 / §5.2） | 废料 500(+300/仓储)、晶体 200(+150)、生物质 150(+100) | 存量有界，永不通胀；闲置 surplus 被丢弃 |
| ② 离线衰减 | 离线产能骤降（§3.3 / §5.3） | K_offline: 0.30（≤8h）→ 0.10（>8h） | 切断"挂机即富"路径，在线才满产 |
| ③ 进攻消耗 | 发起 PVP 预缴成本（§3.4 / §5.3） | 每次出击 废料 50 + 生物质 20 | 掠夺是双向消耗，进攻方也持续泄库 |
| ④ 波次消耗 | 每波扣弹药/应急（§3.5 / §5.5） | 废料 20×(1+0.08(w−1))、生物质 10×(1+0.05(w−1)) | 90s 周期稳定泄流，约 800–1500 废料/时 |

**平衡投影（Lv4 中期 · 16 房间，含 4 生产废/1 生产晶/3 居住/1 仓储）：**
- 在线净产出/时：废料 ≈ 48×60×(1.25 均等级)×1.10 ≈ **3110**；生物质 ≈ 15×60×1.2 ≈ **1080**；晶体 ≈ 1.5×60 ≈ **90**。
- 消耗/时：波次(40 波) 废料 ≈ 800–1500、生物质 ≈ 400–600；建造/升级均摊 废料 ≈ 1000、晶体 ≈ 200、生物质 ≈ 400；PVP 出击(2 次/时) 废料 100、生物质 40。
- **结论**：活跃玩家总消耗 ≈ 产出，存量维持在软上限内的健康带；**纯囤积不消耗者** 废料在约 `1700÷3110×60 ≈ 33min` 触顶后被弃置——证明软上限为硬兜底，通胀不可发生。离线者产能降至 30%/10%，更无堆积可能。

**监控与调参钩子**（供平衡 pass）：若实测某资源中长期贴近软上限且利用率<20%，下调该房基础产出 10% 或上调对应波次消耗系数；若玩家普遍卡在"缺晶体"，上调实验转化比（当前 8:1）或降低晶体软上限基线。
